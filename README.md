
# Data Cleaning Using Python and Pandas

## Project Overview
This project focuses on importing, inspecting, cleaning, and preparing a dataset for further analysis using Python and Pandas.

## Objectives
- Import a dataset using Pandas.
- Inspect dataset structure and data types.
- Identify missing values and duplicate records.
- Handle null values.
- Remove duplicate records.
- Correct inconsistent data entries.
- Convert columns into appropriate data types.
- Export the cleaned dataset as a CSV file.

## Tools & Technologies
- Python
- Pandas
- Google Colab
- CSV

## Project Files
- data_cleaning.ipynb – Jupyter Notebook containing the complete data cleaning process.
- cleaned_employee_dataset.csv – Final cleaned dataset.

## Key Learnings
Learned how to use Pandas for data inspection, data cleaning, handling missing values, removing duplicates, and preparing structured datasets for analysis.
